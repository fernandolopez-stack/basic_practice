    • The full flow, step by step

    Click "Copy" and paste each command into your terminal.

    1. Clone the repository (first time only)

      Download a copy of the project to your computer. Replace the URL with your repository's.

      git clone https://github.com/YOUR-USERNAME/learn-github.git
      cd learn-github

    2. Create a new branch

      Never work directly on main. A branch is your space to experiment without breaking anything.

      git switch -c my-first-change

    3. Make your change

      Open index.html in your editor, edit the practice area and save. To see it, open the file in your browser.

    4. Check what changed

      git status
      git diff

      Green with + is what you added. Red with - is what you removed.

    5. Stage and save the commit

      add chooses which changes go in. commit saves them to the history with a message explaining what you did.

      git add index.html
      git commit -m "Add my name to the learners list"

    6. Push your branch to GitHub

      git push -u origin my-first-change

    7. Open the Pull Request

      Go to your repository on GitHub: a green Compare & pull request button will appear. Give it a title, describe your change and click Create pull request. Someone else reviews it and approves it with Merge.

      You can also do it from the terminal if you have the GitHub CLI:

      gh pr create --title "Add my name" --body "My first PR"

    8. After the merge: go back to main and update

      git switch main
      git pull
      git branch -d my-first-change

    Commands you'll use the most

    git log --oneline

    See the commit history, one line per commit.

    git restore index.html

    Discard your uncommitted changes in that file.

    git branch

    Lists your branches. The one with * is the one you're on.

    git pull

    Fetches new changes from GitHub. Do it before you start working.
